# Varnothsava 2026

Official website for Varnothsava 2026 — Karnataka's grandest inter-collegiate cultural and technical festival hosted by SMVITM, Bantakal, Udupi.

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS 3.4
- **Animations:** Framer Motion
- **Language:** TypeScript
- **Deployment:** Vercel

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/chethankotian2005/Varnothsava-2026.git

# Navigate to project directory
cd Varnothsava-2026

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

### Build for Production

```bash
# Create optimized production build
npm run build

# Start production server
npm start
```

## Deployment

### Vercel (Recommended)

1. Push to GitHub
2. Import project in [Vercel Dashboard](https://vercel.com/dashboard)
3. Vercel auto-detects Next.js configuration
4. Deploy

### Manual Deployment

```bash
npm run build
npm start
```
